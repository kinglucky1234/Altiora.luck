## 迭代 1：目标规划 + 自适应重规划

**问题**：最初只有「日程冲突检测」一个功能，用户提出要加「目标规划」和「动态反馈重规划」。

**用户 Prompt 链**：
> 想加上有目标规划，要思考如何输入和输出，除了初始输入还要加上可以添加自己当时状态，用来调整计划重新规划。我们先想前端界面和功能

**AI 输出**：从用户旅程倒推，提出「输入目标 → 分身出计划 → 你执行 → 录真实状态 → 分身自动重规划 → 循环」核心闭环。

## 迭代 4：大模型配置面板 + 语音输出

**问题**：LLM 接入之后，「谁的 Key、花谁的钱」变成真问题；同时用户要求助手能出声。

**用户 Prompt 链**：
> 所以以后所用用户都用我的钱是吗，或者弄个接口自己配置自己的
> 你在页面弄啊弄个配置的供应商模型url还有apikey还有请求头。
> 原来的模型怎么发声音，我记得可以用免费的本地模型

**AI 输出**：

1. 判定为 BYOK（Bring Your Own Key）：Key 只存浏览器 localStorage，每请求临时透传，服务端不落盘、不写日志；自填 URL 只允许公网 https，挡内网探测。
2. 配置面板补齐 5 个字段：厂商 / API Key / 模型名 / URL / 额外请求头（`Key: Value` 逐行）。
3. 朗读改为系统自带 TTS（免费离线），自动挑中文音色，加右上角总开关 + 每条消息 ▶ 重听 + 长句分段，解决 Chrome 念长文中断。
