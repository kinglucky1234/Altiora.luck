# Altiora · 未来的我

> 用户理想中更好的自己在电脑里的投影 —— 数字孪生分身 + 代价测算引擎
> 赛道：AI 创新应用挑战赛 · 个人效能与数字孪生具身仿真

## 1. 一句话定位

市面上的 AI 助手、日历、习惯养成 App 都在**替你做决定**。

Altiora 不替你决定 —— **它只把每个选择的代价算清楚，让你自己挑**。

## 2. 三段式架构

```
用户说话
   ↓
① AI 翻译官    把自然语言 → 结构化事件 / 情绪标签（LLM，失败自动退回规则）
   ↓
② 计算器       纯确定性代码，永不调用大模型；同一输入永远同一输出
   ↓
③ AI 表达      只把情绪与闲聊翻译成人话（日程结论一律由计算器给）
   ↓
用户看到
```

**关键约束：第 ② 步不含任何概率成分。** 家教 2 小时 × 80 元 = 160 元，第 100 次算也是 160。这是用户能信任它的唯一理由。

LLM 的边界被写死在代码里（`Altiora/backend/llm.py`）：

- 它只输出结构化字段（intent / event / memory / goal / 情绪 / 一句回话），**不输出任何时间差、金钱、代价**；
- 服务端硬约束：`intent` 不是 `emotion` / `chat` 时，模型生成的 `reply` 会被直接丢弃，不允许它替计算器下结论；
- 用户没说结束时间，`event` 就是 `null` —— 宁可追问一句，也不替用户编时间。

没有 Key 时整条链路自动切到本地规则，页面右上角显示「本地规则」；配了 Key 显示「AI 在线」。两种模式功能都完整。

## 2.1 评委 90 秒上手

**不需要注册、不需要装 Python、不需要开后台。一个 HTML 文件就是完整程序：双击 `Altiora-未来的我.html`。**

| 你能得到 | 怎么来的 |
|---|---|
| 打字对话、排日程、算冲突代价、刷新不丢 | 双击就能用，全部在前端完成 |
| 语音输入 | 浏览器自带识别：用 Chrome / Edge 打开 `http://localhost` 或 https 页面时点麦克风即可，不装 Python、不下模型 |
| AI 在线（口语理解更准、话术更像人） | 点右上角状态标签，30 秒填自己的 Key，浏览器直连厂商 |

**关于语音的硬限制**：浏览器只在 `localhost` / https 下给麦克风权限，双击 `file://` 页面时任何网页都拿不到麦克风，这是浏览器规则，不是本项目的问题。评委只看文字链路时完全不需要 Python；要语音就在项目目录运行 `python server.py`，浏览器打开 `http://localhost:8000`。

到这一步就是完整体验：球的四种表情、冲突卡片、真实修改日程、刷新不丢、没有重开键。「AI 在线」只是让理解更准，不是功能前提。

想专门看大模型部分，两条路：

| 方式 | 操作 | 适合 |
|---|---|---|
| 看演示视频 | 提交的 5-8 分钟视频里有 AI 在线模式的完整链路 | 最快，零配置 |
| 自己配 | 点右上角状态标签，30 秒填完自己的 Key | 想亲手验 |

> 仓库里**不含任何 API Key**。作者的 Key 只存在本机浏览器（localStorage），用于录制演示视频，不进提交物。

语音输出用的是**系统自带的语音合成**（Windows 的 Huihui / Xiaoxiao、macOS 的 Tingting），免费、离线、不用下载模型。右上角小喇叭开关，开了以后回复会念出来，每条回复旁边也能点 ▶ 单独重听。系统里没有中文语音时：Windows「设置 → 时间和语言 → 语音」里加一个中文语音包即可。

## 2.2 记忆三层（长期 / 聊天 / 日记）

记多了会像监视，记少了会每句都从零开始。所以分三层，各管各的：

| 层 | 存什么 | 保留多久 | 谁用 |
|---|---|---|---|
| 长期记忆 | 你亲口说的目标、软肋、睡眠硬约束、规矩 | 一直 | 计算器的输入。模型不能改它，只有明说才写 |
| 聊天记忆 | 最近 3 轮对话原文 | 超 6 条就滚掉 | 只用于接住半句（「就那个」「三点」），不进长期记忆 |
| 日记 | 每次聊完一行「日期：摘要」 | 最多 180 行 | 平时完全不出现；隔 3 天以上没来，开场翻最近一条：「上次（10月20日）你说想成为科学家，后来怎么样了？」 |

三条约束：

- 日记是**摘要**，不是聊天记录；写的时候只留事实（目标、排了什么、那会儿的状态），不留原话
- 聊天记忆**只滚不沉淀**，所以不会出现「三周前你说过」这种越界
- 只有久别才翻日记，每天都来的人永远看不到它，不会被「它一直记着我」压到

## 3. 十 分钟极速复现

### 0-2 分钟：环境准备

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11、macOS 12+、Linux |
| Python | **3.8 及以上**（`python --version` 可验证） |
| 浏览器 | Chrome / Edge（语音输入依赖 Web Audio + MediaRecorder） |
| 磁盘 | 约 150 MB |
| 网络 | 仅首次装依赖需要；**本地规则模式完全离线**，AI 在线模式需联网直连厂商 API |

> Windows 安装 Python 时务必勾选 **Add Python to PATH**。

### 2-5 分钟：拉代码 + 装依赖

```bash
git clone https://github.com/kinglucky1234/Altiora.luck.git
cd Altiora.luck/Altiora
pip install -r requirements.txt
```

依赖清单（`requirements.txt`）：

```
fastapi            # Web 服务
uvicorn            # ASGI 服务器
python-multipart   # 接收前端上传的录音
vosk               # 离线中文语音识别
```

### 5-6 分钟：启动（只有想用语音时才需要）

```bash
pip install -r requirements.txt
python server.py
```

看到 `Uvicorn running on http://0.0.0.0:8000`，浏览器打开 **http://localhost:8000**。

> 评委不需要这一步：双击 HTML 就能用文字与 AI。只有想在这台机器上录音识别时才起服务。

> 为什么双击 HTML 录不了音：浏览器只在 `localhost` / https 下给麦克风权限，`file://` 页面一律拒绝，任何网页都一样。

### 出问题先跑自检

```bash
python3 自检.py
```

十项检查：Python 版本、四个依赖是否装齐、语音模型是否完整、前端关键控件是否存在、页面里有没有混进真实 API Key、服务能否启动、识别接口是否通。不联网、不调大模型、不消耗额度；全过退出码 0，有失败退出码 1 并直接告诉你怎么修。

### 6-10 分钟：验证五条链路

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 点麦克风，说「今天没睡好」 | 约 1-3 秒后出现汉字气泡，AI 用一句话接住情绪 |
| 2 | 打字「我明天下午要和导师讨论」 | 听懂意图，但时间不全 → 追问「几点到几点」，不替你编时间 |
| 3 | 打字「周五下午3点到5点去家教」 | 抽成事件排进时间轴，并算出撞了几处、代价在哪一页 |
| 4 | 打字「记住，我晚上容易刷手机」 | 一句话确认，写入本地画像 |
| 5 | 点输入框右侧气泡图标 | 进入全屏对话记录，AI 消息可回放朗读 |

## 4. 环境变量

复制模板：

```bash
cp .env.example .env
```

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `8000` | 服务端口，被占用时改成 8001 等 |
| `VOSK_MODEL_PATH` | 内置模型路径 | 换用其他 Vosk 中文模型时填写绝对路径 |
| `LLM_API_KEY` | 空 | 大模型 Key。留空 = 本地规则模式，功能完整 |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | OpenAI 兼容地址（DeepSeek / 通义 / 火山方舟均可） |
| `LLM_MODEL` | `gpt-4o-mini` | 模型名或方舟接入点 ID |

### 4.1 大模型：先想清楚「谁付钱」

| 场景 | 怎么配 | 花谁的钱 |
|---|---|---|
| 自己一个人用 | 页面里填，或写进 `.env` | 你的 |
| 开放给别人用（公网部署 / 局域网共享） | **不要填 `.env`**，让每个人在页面里配自己的 | 各自的 |

页面里的方式（BYOK，Bring Your Own Key）：

1. 打开页面，点右上角「本地规则 / AI 在线」标签
2. 选厂商 → 粘贴自己的 API Key → 保存 → 测试连接。URL、模型名都能改，需要时还能加额外请求头（一行一个 `Key: Value`，中转站常用）
3. Key 只存在他自己的浏览器里（localStorage）；请求由浏览器直连厂商，不经过任何中转，服务端不落盘、不写日志、不进仓库
4. 换电脑、换浏览器、点「清除」，Key 就没了

服务端还加了一道限制：用户自填的 Base URL 只接受公网 `https://`，禁止 `localhost`、`127.x`、`10.x`、`192.168.x`、`172.16-31.x` 等内网地址，**并在 DNS 解析后校验返回 IP 是否落在内网范围（防 DNS 重绑定）**，避免被拿去探测内网。

自己一个人用时，也可以走 `.env`：

```bash
cp .env.example .env
# 编辑 .env，填三行，例如 DeepSeek：
# LLM_API_KEY=sk-xxxx
# LLM_BASE_URL=https://api.deepseek.com/v1
# LLM_MODEL=deepseek-chat
python3 server.py
```

重启后页面右上角从「本地规则」变成「AI 在线」，口语化的说法（「我明天下午要和导师讨论」）也能被听懂。其他厂商的地址与模型名见 `.env.example` 注释。

> 全部留空也能完整跑通 —— 这是本项目「零外部依赖」的设计目标，也是断网/无 Key 场景下的兜底。

## 6. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `python: command not found` | 未装 Python 或未加 PATH | 重装并勾选 Add Python to PATH，或用 `python3` |
| `ModuleNotFoundError: fastapi` | 依赖没装到当前解释器 | `python -m pip install -r requirements.txt` |
| 端口被占用 (`Address already in use`) | 8000 已被其它程序占用 | `set PORT=8001` 后重启，或 Windows `netstat -ano | findstr :8000` |
| 页面能开，点麦克风没反应 | 浏览器不允许麦克风 / 非 localhost | 用 Chrome 打开 `http://localhost:8000`，并在地址栏允许麦克风 |
| 语音一直返回空文本 | 模型目录缺失 | 确认 `Altiora/backend/model/vosk-model-small-cn-0.22/` 存在（约 66 MB） |
| 识别很慢（>5 秒） | 首次加载模型 | 第一次识别会加载模型，之后每次约 1-3 秒 |

## 8. 设计原则（为什么这样做）

- **不给记分板，只给账单。** 完成率会掉分，一掉分用户就想「重开」；代价不会判你不及格。
- **没有重开键。** 断了几天回来显示「接着走」，不显示「已中断」。
- **代价卡片只在真冲突时出现。** 情绪场景只出一句话 —— 人难受时不需要表格。
- **球只留眼睛和嘴。** 不画鼻子耳朵，把五官收到最少，停在抽象具身，避开恐怖谷。
