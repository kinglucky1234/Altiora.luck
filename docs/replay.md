# 演进脚本（Replay）

> 用途：赛题要求「通过 Prompt 记录和演进脚本进行确定性复现」。本文件把六个迭代与三个关键 Bug 的协作过程，写成**照着做就能复现**的步骤。
> 每条都含四段：**我提了什么 → AI 给了什么建议 → 我怎么判断/引导 → 怎么验证它真的修好了**。
> 对话原文见 [AI协同对话历史.md](../AI协同对话历史.md)，截图见 `prompt-snapshots/`，代码位置按函数名可在 [Altiora-未来的我.html](../Altiora-未来的我.html) 中搜到。

## 0. 复现前置（3 分钟）

```bash
git clone https://github.com/kinglucky1234/Altiora.luck.git && cd Altiora.luck
python3 自检.py          # 依赖、模型、控件、Key 泄漏、脚本语法，全过退出码 0
python3 server.py        # 或直接双击 Altiora-未来的我.html（文字功能零依赖）
```

三个成功标志：

1. 打开 `http://localhost:8000`，右上角显示「AI 在线」（未配 Key 时显示「本地规则」，功能同样完整）；
2. 发「今天有点累」，收到一句接住情绪的话，且不弹表格；
3. 发「周五下午3点开会」，时间轴出现事件；再发「周五下午3点半做家教，两小时」，出现 A/B/C 代价卡片。

## 1. 六个迭代（Prompt → 建议 → 引导 → 验证）

| 迭代 | 我提的 Prompt（原文摘录） | AI 给了什么 | 我如何判断与引导 | 落到哪里 · 怎么验证 | 快照 |
|---|---|---|---|---|---|
| 1 目标规划闭环 | 「想加上目标规划……除了初始输入还要加上可以添加自己当时状态，用来调整计划重新规划」 | 目标→计划→执行→录状态→重规划 的闭环 | 我判定「自适应」是赛题关键词，要求重规划**不能由 LLM 自由发挥**，必须本地确定性计算 | `buildTodayPlan()` / `focusWindowOf()`；改精力高峰后重新生成方案，脑力活应挪进高峰窗 | `iter1-01~03` |
| 2 功能分层 | 「先别加功能，分清哪些必须有」 | P0/P1/P2 分层；建议上数据库 | 我否掉数据库：单人本地场景用 localStorage 足够，少一层部署风险 | `DATA` / `saveData()`；刷新页面后日程与画像不丢 | `iter2-01~02` |
| 3 产品形式 | 「小白用户打开第一眼该看到什么」 | 表单式配置 | 我要求先出单 HTML 原型，左输入右时间轴，2 分 25 秒能点 | 单文件结构；双击 HTML 即可对话 | `iter3-01~02` |
| 4 模型与语音 | 「想在页面里填自己的 Key，还要能念出来」 | 配置面板 + 系统 TTS | 我加约束：Key 只存 localStorage、直连厂商；自填 URL 必须校验内网地址 | `directChat()` / `speak()`；填错 Key 应自动退回本地规则 | `iter4-01~02` |
| 5 目标抽取 Bug | 「我输入『你好啊，我想当科学家』，直接把原话放进长期目标了」 | 把「检测」与「抽取」拆两步，七步规则 | 我要求给正反例对照，9 例全过才准提交 | `extractGoal()`；9 例见技术文档表 6-2 | `iter5-01` |
| 6 记忆三层 | 「长期记忆、聊天记忆、日记分开……超过 3 天没来，翻日记上次你说要考试后来怎么样了」 | 三层按保留时长划边界 | 我要求日记只存摘要、不存原话；聊天记忆只接半句 | `SESS` / `diary`；把日期调到 4 天前重开，开场应回访 | `iter6-01` |

## 2. 三条 Bug 链（可复现的输入 → 期望）

| 链 | 复现输入 | 修好前的错误 | 修好后的期望 | 判据 |
|---|---|---|---|---|
| A 时长被吞 | 「我明天下午两点半到五点看书」 | 听成「半小时」 | 事件 14:30-17:00，回执写明 2.5 小时 | 时间差 = 150 分钟 |
| B 目标名被吞 | 「我想考六级，12月14号考试」 | 目标名含日期与逗号 | 目标名 = 「考六级」，日期进截止日 | 画像里目标名不含「，」 |
| C 歧义小时 | 「3点开会」 | 静默丢弃或猜错上下午 | 先反问「凌晨还是下午」，回「下午」→ 15:00-16:00，并说明按 1 小时估 | 30 分钟内可补全，过期不再接 |

三链的共同方法：**先固定输入与期望 → 让 AI 定位根因 → 只改根因不顺手重构 → 用上述判据回归 → 同时检查不该误伤的邻近用例**（如「我3点就醒了」不得被当成日程）。
