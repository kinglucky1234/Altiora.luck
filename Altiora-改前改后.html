Altiora · 改前 / 改后

挑 10 条真实发生过的问题。左边是它当时的回答，右边是现在的回答。每条都写明「怎么判定改好了」——不是看起来对了，是能重复验一遍。

10 条实证 全部可在网页里复现 截至 2026-11-14 无 API Key 也能验（走本地规则）
改前：当时的真实输出 改后：现在的真实输出
01「两个半小时」被听成半小时时长解析顺序
你说：六级每天两个半小时
改前
记住了：六级，每天 30 分钟。
改后
记住了：六级，每天 2.5 小时。今天 08:00 到 10:30 空着，就定这儿？
判据：回复出现「2.5 小时」，且建议时段跨度正好 150 分钟。回归：「半小时」「一个半」「三个半」仍分别为 30 / 90 / 210 分钟。
02目标名被记成「六级425」目标名清洗
你说：六级每天两个半小时，12月19号考，425分过线
改前
记住了：六级425，每天 2.5 小时。（分数、过线字样被当成名字的一部分）
改后
记住了：六级，每天 2.5 小时。（分数留在「目标分数」，不混进名字）
判据：画像页的目标名是「六级」，不是「六级425」，也不是整句话。
03说「帮我排计划」，它只反问钟点排计划分支
你说：帮我排到考前的计划，晚上8点开始
改前
你每天那两个半小时，想定在几点到几点？（把「定时长」的活推回给用户）
改后
排好了：35 天 63 场，从 11月14日 20:00 的「阅读精读·六级」开始。我指给你看。（回「行」才落进时间轴）
判据：场次跨多天；回一句「行」后，时间轴条数真的增加；回「算了」则一条不加。
04排计划只写「英语」两个字按内容拆块
你说：帮我排这周的计划，7点开始
改前
日程里出现一条「英语」，时长 150 分钟，没有说这 150 分钟干什么。
改后
拆成「单词 30 分·英语」→「听力 1 篇·英语」→「阅读精读·英语」多块，标注时长的先占，其余按剩余时间平分，每块不少于 15 分钟。
判据：时间轴里同一天出现多块带内容名的事件，而不是一条笼统的科目名。
05「3点开会」被直接丢掉歧义时间先反问
你说：3点开会 → 下午
改前
「3点开会」——这句我没完全接住。你想让我帮你做什么？（要么丢掉，要么直接猜凌晨 3 点排进去）
改后
「开会」——3 点，是凌晨还是下午？回一句「下午」或「上午」，我就排进去。
你：下午
→「开会 15:00-16:00」排进去了（你只说了开始，我先按 1 小时算）。
判据：第一句不新建事件；第二句只回「下午」即可落地；30 分钟不回应则 pending 过期，不会第二天冒出错时间。
06「我3点就醒了」被当成日程已发生的事不排
你说：我3点就醒了
改前
时间轴里多出一条「醒了 03:00-04:00」。（把状态描述当成了待办）
改后
「3点就醒了」——这句我没完全接住。你想让我帮你做什么？（不建事件，也不追问凌晨还是下午）
判据：时间轴无新增；命中「醒/睡/起床/到家/下班/迟到」的句子一律不排。
07安慰是通用的，不认得你是谁画像参与回话
你先说过：记住：我吃软不吃硬，别骂我　然后你说：我就是个废物
改前
别这么说自己，每个人都会有低谷期，调整好心态就好。（放到任何人身上都成立）
改后
你自己说过「吃软不吃硬」——先停一下。骂自己不会让事情变少，只会让你更想重开。
判据：回复里出现用户自己说过的原话；没有匹配原话时宁可不加，绝不编造。
08主动关心只有「没画勾」，没有分量带倒计时
场景：目标「六级」连续两天没完成，今天还有空档
改前
「六级」这两天没画上勾。今天 20:00 到 22:30 空着——给它？
改后
「六级」这两天没画上勾。离「六级」还有 35 天。今天 20:00 到 22:30 空着——给它？（短期目标不出现这句，不催）
判据：带截止日期的长期目标才出现倒计时；一天最多主动开口一次。
09评委打开作品，得先自己找 Key服务端同源部署
场景：评委第一次打开
改前
右上角点「模型」→ 粘贴 API Key → 刷新，才有 AI。（多数评委在这一步就放弃，等于没看到 AI）
改后
打开在线地址直接对话，AI 已在线；接口与页面同源，不走浏览器直连，所以既没有混合内容拦截，也不把 Key 暴露给前端。
判据：GET /api/health 返回 "llm":true；连续请求超限后返回 429，前端自动回退本地规则而不报错。
10换了入口就「失忆」数据兜底与镜像同步
场景：从另一个链接打开，发现所有记录都没了
改前
打开的是旧版页面／不同入口，看到空白的自己，以为数据丢了。
改后
每天自动留一份本地备份，画像页可「恢复今天的自动备份」；仓库内五份 HTML 镜像 md5 一致，任何入口都是同一版。
判据：五份文件 md5sum 去重后只有 1 个值；画像页能看到备份并可一键恢复。
